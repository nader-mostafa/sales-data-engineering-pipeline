# Power BI Dashboard

The final analytical layer was connected to Power BI to build an interactive Sales Performance Dashboard.

## Dashboard Components

### KPIs
- Total Sales
- Total Profit
- Units Sold
- Distinct Orders

### Analysis
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Sales by State
- State Sales Ranking

### Filters
- Year
- Region
- Category

## Data Source

The dashboard is connected to the SQL Server Data Warehouse and uses the analytical data model built from the fact and dimension views.
